# Series Explorer

Explorador de series construido con JavaScript vanilla y datos de [TVmaze](https://www.tvmaze.com/).

## Estado

Proyecto en construcción. La estructura inicial está preparada; la carga de datos y las funcionalidades se añadirán paso a paso.

## Ejecutar en local

Sirve esta carpeta mediante un servidor HTTP local y abre la dirección que te proporcione. No abras `index.html` directamente como archivo: el proyecto consultará una API desde el navegador.

## Atribución

Los datos de series proceden de TVmaze. Consulta su [API y licencia](https://www.tvmaze.com/api).
